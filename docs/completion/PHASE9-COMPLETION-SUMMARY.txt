SETUP INSTRUCTIONS
================================================================================

1. GET UPSTOX API CREDENTIALS:
   - Go to https://upstox.com/developer/
   - Create new app
   - Copy API Key and API Secret
   - Register redirect URI: http://localhost:3000/api/auth/upstox/callback

2. CONFIGURE ENVIRONMENT:
   Edit backend/.env:
   ```
   UPSTOX_API_KEY=your_api_key_here
   UPSTOX_API_SECRET=your_api_secret_here
   UPSTOX_REDIRECT_URI=http://localhost:3000/api/auth/upstox/callback
   ```

3. OAUTH FLOW:
   - Generate authorization URL
   - Login and authorize
   - Get authorization code
   - Connect adapter with code
   - Token valid until 3:30 AM next day

4. WEBSOCKET SETUP:
   - Connect adapter first
   - Get WebSocket: adapter.getWebSocket()
   - Connect: ws.connect()
   - Subscribe: ws.subscribeOrderFeed()

================================================================================
UPSTOX-SPECIFIC NOTES
================================================================================

1. INSTRUMENT KEYS:
   - Format: EXCHANGE|ISIN
   - Example: NSE_EQ|INE669E01016 (not "RELIANCE")
   - Get from Upstox BOD instruments file

2. PRODUCT TYPES:
   - D = Delivery (CNC)
   - I = Intraday (MIS)
   - MTF = Margin Trading Facility

3. ORDER TYPES:
   - MARKET = Immediate execution
   - LIMIT = Specific price
   - SL = Stop Loss Limit
   - SL-M = Stop Loss Market

4. TOKEN VALIDITY:
   - Expires 3:30 AM next trading day
   - Must re-authenticate daily
   - No refresh token mechanism

5. HFT ENDPOINTS:
   - api-hft.upstox.com
   - Lower latency
   - Used automatically

TRADE EXECUTION FLOW
================================================================================

WebSocket receives order update
  ↓
UpstoxWebSocket checks status
  ↓
If status = 'complete' or 'traded' AND filled_quantity > 0
  ↓
Emit 'executionUpdate' event
  ↓
webSocketService (existing)
  ↓
server.js handler (existing)
  ↓
tradeExecutionService.processExecution() (existing)
  ↓
SQLite database (automatic duplicate prevention)
